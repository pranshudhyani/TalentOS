# TalentOS

TalentOS is an AI-powered Talent Intelligence & Operations System designed for enterprise recruiting, candidate matching, and workforce planning.

## Architecture & Layout

- **`backend/`**: FastAPI backend service powering AI engines, data models, and REST APIs.
- **`frontend/`**: Web application interface for candidate tracking and dashboard metrics.
- **`docs/`**: Product specs, architecture notes, runbooks, and interview prep guides.
- **`infra/`**: Nginx proxy and telemetry/monitoring configurations.
- **`scripts/`**: Development and deployment helpers.

## Getting Started

### Local Setup with Docker Compose
```bash
docker-compose up --build
```
