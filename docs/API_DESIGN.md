# API Design Specification - TalentOS

## API Endpoints

### Candidates API
- `GET /api/v1/candidates` - Retrieve list of candidates.
- `POST /api/v1/candidates` - Create a new candidate profile.
- `GET /api/v1/candidates/{id}` - Get candidate profile details.

### Jobs API
- `GET /api/v1/jobs` - List open job positions.
- `POST /api/v1/jobs` - Post a new job position.
